# Overseer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One read-only view across every project: a code-built digest per project (`GET api/overview`, `tmux-ctl overview`), code-driven notifications (macOS banners and the board tab) for needs-you, finished plans, failed runs, idle leads, high context and high usage, a haiku overseer agent that answers questions from the digest and can't write, and the board's home page as the overseer view.

**Architecture:** `board/overview.py` is a pure builder over state the board already has (planview, activity, artifacts, usage) with injected paths and tmux; `board/notify.py` diffs successive overviews into events with a once-per-appearance latch and a 5-minute per-kind rate limit, delivering through an injected `osascript` runner; `board/server.py` builds the overview every 10 s in a thread, serves it with an ETag and re-ensures the overseer session; `bin/tmux-overseer` owns the session lifecycle (called by `tmux-dev-layout`, the server and `tmux-session-closed`), `bin/claude-overseer` starts haiku at low effort with `claude/overseer-settings.json` (read-only by `dontAsk` + deny rules) and `claude/overseer.md`; `board/index.html` routes `/` to the home view and `#<project>` to the project pages.

**Tech Stack:** Python 3 stdlib (unittest, sqlite3, http.server), zsh, tmux 3.8, Claude Code 2.1.312 (`--settings`, `--effort`, permission rules), macOS `osascript`, the Notifications Web API.

**Spec:** `docs/superpowers/specs/2026-10-28-overseer-design.md`

## Global Constraints

- **Repo:** `~/agent-board`. It is the live install: plans execute in a worktree under `.claude/worktrees/`, never in the live checkout. Commands are in `~/agent-board/CLAUDE.md`. Conventional commits with scope: `feat(board): …`, `feat(tmux-ctl): …`, `docs(board): …`.
- **Workspace:** run in a new worktree `.claude/worktrees/overseer` on branch `feat/overseer` cut from `main`; no question about working on main.
- **Precondition:** plan 1 of the round, `docs/superpowers/plans/2026-10-28-shared-project-context.md`, has merged into `main` (fixed order: shared-context, overseer, teams, night mode). This plan uses nothing from it, and nothing here may depend on the later teams or night-mode plans. Teams adds notifier event 7 and night mode adds `teammate_context_budget` later: keep `notify.conditions()` and `usage.OPTIONAL_ALERTS` extensible (a new kind is one `add(...)` line; a new key is one tuple entry).
- **Commit steps** end with the attribution trailer your harness specifies; never a literal Co-Authored-By line.
- **Agents' shell is zsh** (gotchas in `~/.claude/CLAUDE.md`): brace a variable before a colon (`"=${OV}:claude"`, never `"=$OV:claude"`, where `:c` is a modifier; this plan's author hit exactly that in `bin/tmux-overseer`); quote `=name` targets; never name a variable `path`. Scratch tmux servers start with `-L <sock> -f /dev/null` (`tools/tests/lib.zsh` does). Suite verdicts come from the runner's summary line (`OK` / `FAILED` for unittest, `ALL PASS` / `N FAILED` for a zsh test), or `zsh tools/tests/run-all.zsh > F; echo rc=$?` plus `grep -c '^FAIL' F` for run-all, which prints no aggregate. Never from `tail`.
- **Record shape** (the contract between `overview.py`, `notify.py`, `server.py`, `tmux-ctl overview` and the page; `overview.RECORD_KEYS` fixes the order): `{"project", "path", "attached", "plan": {"name", "active", "done", "total", "in_progress": [{"id", "subject", "owner", "state"}]}, "needs_you": [{"window", "pane", "kind"}], "last_run": {"id", "cmd", "exit", "ts", "age_s", "summary"} | null, "lead": {"status": "working|waiting|ready|missing", "last_active": epoch|null, "idle_s": int|null}, "artifacts": [{"path", "kind", "title", "ts", "agent"}] (≤ 3, newest first), "epoch": int, "alerts": [{"kind", "label", "detail", "session", "context_pct"}], "spend_today": float|null}`. `GET api/overview` = `{"generated", "projects": [record], "events": [event], "overseer": {"session", "running", "window_index"}}`. Event = `{"id", "ts", "project", "kind", "key", "title", "text"}`, kinds `needs_you | plan_done | test_failed | lead_idle | context | usage`.
- **Fixed names:** tmux session `overseer` (option `@tc_overseer 1`), window `claude`; env `TC_NOTIFY`, `TC_OVERSEER`, `TC_OVERSEER_CMD` (test seam), `TMUX_DASH_STATE` (token dir for `tmux-ctl overview`); `usage-alerts.json` key `day_total` (optional, no default); notifier rate limit 300 s, lead-idle threshold 900 s, overview period 10 s (`server.OVERVIEW_EVERY`).
- **Permissions, not prompt:** in Claude Code, deny rules beat allow rules in every scope, so a bare `Bash` deny would also block the allowed `tmux-ctl overview`; "any other Bash is denied" is `defaultMode: "dontAsk"` (auto-denies every call no allow rule matches, never prompts) plus explicit denies of the write tools and the writing `tmux-ctl` subcommands. Rule `Bash(tmux-ctl overview *)` (with the space) matches the bare command and its arguments, not `tmux-ctl overviewX`. Source: Claude Code docs `permissions`, `permission-modes`, `settings-reference` (read 2026-10-28 by a docs agent); `claude --help` 2.1.312 lists `--effort (low, medium, high, xhigh, max)`, `-n, --name`, `--settings <file-or-json>`, `--append-system-prompt-file`.
- **Path parameters for test isolation:** every builder takes `home`, `state_dir`, `tmux` (a `tmux(*args, check=False) -> stdout` callable) as parameters; tests put files at the real relative layout: `<home>/sessions/*.json`, `<home>/tasks/session-<id8>/*.json`, `<state>/artifacts-<project>.jsonl`, `<state>/runs-<project>.jsonl`, `<state>/lineage-<project>.jsonl`, `<state>/usage.sqlite`, `<TMUX_DASH_STATE>/token`. Board tests set `TC_STATE` to a temp dir and never read the real HOME, state dir or board.
- **Fixtures:** `board/tests/fixtures/planview/` (captured and scrubbed, see its README) is reused for sessions, tasks and the manifest. The run record and the live-usage entry in `test_overview.py` are synthetic but shape-exact (keys copied from a real `runs-agent-board.jsonl` record read through the live board's `api/runs` and from `usage._live_entry()` on 2026-10-28) and labelled so in the test module docstring; the e2e task pairs them with read-only runs on the real board state.
- **The overseer never acts:** no task here gives it a write tool, a team, a plan or `task-observer`. Its prompt says so; its settings enforce it; `test_overseer.py` checks both.
- **Facts probed at plan time (2026-10-28):** `#{window_activity}` is an epoch in seconds per window on tmux 3.8 (`tmux -L probe -f /dev/null list-windows -a -F '#{window_activity}'` → `1793236284`). `osascript -e 'display notification "x" with title "y"'` exits 0 on this Mac, also with escaped `\"` and `\\` inside; the page today has no per-project URL (the project is a tab kept in `localStorage`), so `#<project>` is new and `/` becomes the home. The user's install is the unmigrated one: projects live on the user's default tmux server and the board runs `~/.local/share/tmux-dash -> ~/agent-board/board`; `bin/_tc_bins.zsh` resolves that server for every script here, so nothing in this plan hardcodes `-L agent-board`. The live board at plan time had five projects (Desktop, agent-board, francisco_ruiz, interiors, master-gcp-repo); the local `overview.py` build on that real state printed one line per project (load average 61 at the time).
- **Model routing:** every task carries `modelTier`; code in mechanical tasks was run once by the plan author in a scratch copy of the checkout (unit tests green, named mutations red) and is to be copied verbatim.

**User decisions (already made, spec "Decisions"):**
- All three parts: a per-project summary, asking questions, and notifications.
- Read-only: the overseer never messages, redirects or stops a project's agents; the user goes to the project to act.
- Approach 1: the digest is built by code (no LLM); notifications are code-driven state changes; a mechanical-tier (haiku, low) overseer answers questions from the digest.
- Notifications: macOS banners and the board tab, including high context and high usage with the board's usage-alert thresholds.
- Starts automatically whenever a project has a lead; no button.
- The board's home page is the overseer view.

class DayTotalTest(unittest.TestCase):
    """day_total: an optional usage-alerts.json key with no default; spend_since and day_alert evaluate it."""

    def test_absent_key_is_off(self):
        th, warn = usage.thresholds(self.tmp / "none.json")
        self.assertIsNone(th.get("day_total")); self.assertIsNone(warn)
        self.assertIsNone(usage.day_alert(999.0, th))

    def test_accepted_and_evaluated(self):
        self.p.write_text(json.dumps({"day_total": 10}))
        th, warn = usage.thresholds(self.p)
        self.assertEqual(th["day_total"], 10); self.assertIsNone(warn)
        self.assertIsNone(usage.day_alert(10.0, th))                       # not over
        a = usage.day_alert(12.5, th)

        self.assertIn("$12.50", a["detail"])
        self.assertIsNone(usage.day_alert(None, th))                        # unknown spend never alerts

    def test_invalid_value_warns(self):
        self.p.write_text(json.dumps({"day_total": "ten"}))
        th, warn = usage.thresholds(self.p)
        self.assertIsNone(th.get("day_total")); self.assertIn("day_total", warn)

        conn = usage.connect(self.tmp / "u.sqlite"); self.addCleanup(conn.close)
        f = self.tmp / "p" / "s.jsonl"; f.parent.mkdir()

        self.assertAlmostEqual(usage.spend_since(conn, "/r", since, self.prices), 30.0)   # a + b at $15/Mtok; c other project, d too old
        self.assertEqual(usage.spend_since(conn, "/nowhere", since, self.prices), 0.0)
        self.assertIsNone(usage.spend_since(conn, "/r", since, {"models": {}}))          # all unpriced

#!/usr/bin/env python3
"""overview: one digest record per project, from state the board already has. No LLM.

build(sessions, live, now, *, home, state_dir, tmux, th, spend, activity) -> {"generated", "projects": [record]}
Every input is a parameter: `sessions` is server.build_state()["sessions"], `live` the usage indexer snapshot,
`spend(repo) -> USD or None` today's spend, `activity` {session: {window: epoch}} from `list-windows -a`.
Record fields are fixed (the notifier and the page read them): see RECORD_KEYS. Never raises per project: a failing
piece leaves its field empty (plan with total 0, last_run None, lead missing).

CLI: overview.py [--project NAME] [--json]  prints the live board's /api/overview (token from
${TMUX_DASH_STATE:-~/.local/state/tmux-dash}/token, port TMUX_DASH_PORT); without a board, a local build without
usage data ("source": "local"). `tmux-ctl overview` calls this.
"""
import argparse
import json
import os
import sys
import time
import urllib.request
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))  # python3 -I does not add the script dir
import activity as activity_mod  # noqa: E402
import artifacts, planview, usage  # noqa: E402

RECORD_KEYS = ("project", "path", "attached", "plan", "needs_you", "last_run", "lead", "artifacts", "epoch", "alerts", "spend_today")
ERRORS = (OSError, ValueError, RuntimeError, KeyError, TypeError, AttributeError)


def plan_digest(view):
    tasks = view.get("tasks") or []
    done = sum(1 for t in tasks if t.get("status") == "completed")
    return {"name": view.get("name") or "", "active": bool(view.get("active")), "done": done, "total": len(tasks),
            "in_progress": [{"id": t["id"], "subject": t["subject"], "owner": t.get("owner") or "", "state": t.get("state") or ""}
                            for t in tasks if t.get("status") == "in_progress"]}


def needs_you(s):
    return [{"window": w["name"], "pane": p["id"], "kind": p["kind"]}
            for w in s.get("windows") or [] for p in w.get("panes") or [] if p.get("status") == "waiting"]


def lead_state(s, win_activity, now):
    """status working|waiting|ready from the claude window's first pane, missing without one; last_active from tmux."""
    w = next((w for w in s.get("windows") or [] if w.get("name") == "claude" and w.get("panes")), None)
    if w is None:
        return {"status": "missing", "last_active": None, "idle_s": None}
    p = w["panes"][0]
    status = p.get("status") if p.get("kind") == "claude" else "missing"
    last = (win_activity or {}).get("claude")
    return {"status": status or "missing", "last_active": last, "idle_s": int(max(0, now - last)) if last else None}


def last_run(project, now):
    try:
        rs = activity_mod.runs(project, limit=1)
    except ERRORS:
        return None
    if not rs:
        return None
    r = rs[0]
    return {"id": r.get("id"), "cmd": r.get("cmd") or "", "exit": r.get("exit"), "ts": r.get("ts"),
            "age_s": int(now - (r.get("ts") or now)), "summary": r.get("summary") or ""}


def recent_artifacts(project, n=3):
    try:
        items = artifacts.summary(project)
    except ERRORS:
        return [], 0
    out = [{"path": i["path"] or i["url"], "kind": i["kind"], "title": i.get("title") or "", "ts": i["latest"].get("ts"),
            "agent": i["latest"].get("agent") or ""} for i in items["items"] if not i.get("dismissed")][:n]
    return out, items["epoch"]


def project_alerts(s, live, spend, th):
    repo = s.get("path") or ""
    mine = [e for e in live if repo and usage.in_project(e.get("cwd"), repo)]
    out = [dict(a, session=e["name"], context_pct=e.get("context_pct")) for e in mine for a in e.get("alerts") or []]
    day = usage.day_alert(spend, th)
    if day:
        out.append(dict(day, session=None, context_pct=None))
    return out


def record(s, live, now, *, home, state_dir, tmux, th, spend, activity):
    name = s["name"]
    try:
        view = planview.view(name, s.get("path") or ".", home, state_dir, tmux)
    except Exception:   # noqa: BLE001 - a failing plan view leaves the plan empty
        view = dict(planview.EMPTY)
    try:
        spent = spend(s.get("path") or "") if (spend and s.get("path")) else None
    except Exception:   # noqa: BLE001
        spent = None
    arts, epoch = recent_artifacts(name)
    return {"project": name, "path": s.get("path"), "attached": bool(s.get("attached")),
            "plan": plan_digest(view), "needs_you": needs_you(s), "last_run": last_run(name, now),
            "lead": lead_state(s, (activity or {}).get(name), now), "artifacts": arts, "epoch": epoch,
            "alerts": project_alerts(s, live, spent, th), "spend_today": spent}


def build(sessions, live, now, *, home, state_dir, tmux, th=None, spend=None, activity=None):
    th = th if th is not None else usage.DEFAULT_ALERTS
    projects = [record(s, live or [], now, home=home, state_dir=state_dir, tmux=tmux, th=th, spend=spend, activity=activity)
                for s in sessions if not s["name"].startswith("_web-") and s["name"] != "overseer"]
    return {"generated": now, "projects": projects}


# ---------------------------------------------------------------- CLI

def line(r):
    """One compact line per project for `tmux-ctl overview`."""
    plan = r["plan"]
    parts = [r["project"].ljust(18)]
    parts.append(f"plan {plan['name'] or '-'} {plan['done']}/{plan['total']}" + ("" if plan["active"] else " (idle)"))
    if plan["in_progress"]:
        parts.append("▶ " + ", ".join(f"{t['subject'][:30]}→{t['owner'] or '?'}" for t in plan["in_progress"]))
    if r["needs_you"]:
        parts.append("NEEDS YOU: " + ", ".join(n["window"] for n in r["needs_you"]))
    lead = r["lead"]
    idle = f" {lead['idle_s'] // 60}m" if lead.get("idle_s") is not None and lead["status"] == "ready" else ""
    parts.append(f"lead {lead['status']}{idle}")
    run = r["last_run"]
    if run:
        ex = "running" if run["exit"] is None else f"exit {run['exit']}"
        parts.append(f"run {ex} {run['age_s'] // 60}m ago")
    if r["spend_today"] is not None:
        parts.append(f"${r['spend_today']:.2f} today")
    if r["alerts"]:
        parts.append("alerts " + ", ".join(a["label"] for a in r["alerts"]))
    return " · ".join(parts)


def board_overview(timeout=5):
    """The running board's /api/overview, or None when there is no board (no token file, connection refused)."""
    state = Path(os.environ.get("TMUX_DASH_STATE") or Path.home() / ".local" / "state" / "tmux-dash")
    try:
        tok = (state / "token").read_text().strip()
    except OSError:
        return None
    port = os.environ.get("TMUX_DASH_PORT", "7700")
    try:
        with urllib.request.urlopen(f"http://127.0.0.1:{port}/{tok}/api/overview", timeout=timeout) as r:
            d = json.load(r)
    except (OSError, ValueError):
        return None
    return d if isinstance(d, dict) and "projects" in d else None


def local_overview():
    """A build from this process (no board): pane state from server.py's build, no usage data."""
    os.environ.setdefault("TMUX_DASH_TOKEN", "local")
    import server  # noqa: PLC0415 - heavy; only without a board
    now = time.time()
    st = server.build_state()
    ov = build(st["sessions"], [], now, home=Path.home() / ".claude", state_dir=artifacts.state_dir(), tmux=server.tmux,
               th=usage.thresholds()[0], spend=None, activity=server.window_activity())
    return {**ov, "events": [], "source": "local"}


def main(argv=None):
    ap = argparse.ArgumentParser(prog="overview")
    ap.add_argument("--project")
    ap.add_argument("--json", action="store_true")
    a = ap.parse_args(argv)
    ov = board_overview() or local_overview()
    if a.project:
        ov = {**ov, "projects": [p for p in ov["projects"] if p["project"] == a.project]}
        if not ov["projects"]:
            print(f"overview: no open project named {a.project}", file=sys.stderr)
            return 1
    if a.json:
        print(json.dumps(ov, ensure_ascii=False))
    elif not ov["projects"]:
        print("no open projects")
    else:
        for p in ov["projects"]:
            print(line(p))
    return 0


if __name__ == "__main__":
    sys.exit(main())

```python
"""notify: code-driven events from successive overviews (board/overview.py records), delivered as macOS banners.

Rules (spec 2026-10-28-overseer-design.md): an event fires once when its condition first appears, not again while it
holds, again after it clears and comes back; at most one event of a kind per project every RATE_S seconds; the first
overview, and a project's first appearance, only seed the latch (nothing "appears" at startup). TC_NOTIFY=0 turns
delivery off. The osascript call goes through an injected runner. Pure except for the runner and the clock.
"""
import os
import subprocess
import sys
import time
from collections import deque

KINDS = ("needs_you", "plan_done", "test_failed", "lead_idle", "context", "usage")
RATE_S = 300      # at most one event of a kind per project in this window
IDLE_S = 900      # a lead idle this long with open tasks is event 4
USAGE_KINDS = ("burn", "total", "day_total")


def conditions(ov):
    """Every condition true in one overview: [{project, kind, key, title, text}]. Deterministic order."""
    out = []

    def add(project, kind, key, title, text):
        out.append({"project": project, "kind": kind, "key": str(key), "title": title, "text": text})

    for p in ov.get("projects") or []:
        name = p["project"]
        for n in p.get("needs_you") or []:
            add(name, "needs_you", n["pane"], f"{name}: needs you", f"{n['window']} is waiting for you")
        plan = p.get("plan") or {}
        total, done = plan.get("total") or 0, plan.get("done") or 0
        if total and done == total:
            add(name, "plan_done", plan.get("name") or "", f"{name}: plan finished", f"{plan.get('name') or 'plan'} · {done}/{total} done")
        r = p.get("last_run")
        if r and r.get("exit") not in (None, 0):
            add(name, "test_failed", r["id"], f"{name}: test run failed", f"exit {r['exit']} · {(r.get('cmd') or '')[:80]}")
        lead = p.get("lead") or {}
        idle = lead.get("idle_s")
        if lead.get("status") == "ready" and idle is not None and idle >= IDLE_S and total and done < total:
            add(name, "lead_idle", "lead", f"{name}: lead idle", f"idle {idle // 60} min with {total - done} open task{'s' if total - done != 1 else ''}")
        for a in p.get("alerts") or []:
            who = a.get("session") or name
            if a.get("kind") == "context":
                add(name, "context", who, f"{name}: high context", f"{who} context at {a.get('context_pct')}%")
            elif a.get("kind") in USAGE_KINDS:
                add(name, "usage", f"{a['kind']}:{who}", f"{name}: high usage", f"{who} {a.get('label', '')}".strip())
    return out


def _esc(s):
    return str(s).replace("\\", "\\\\").replace('"', '\\"')


def banner_argv(title, text):
    return ["osascript", "-e", f'display notification "{_esc(text)}" with title "{_esc(title)}"']


def osascript_runner(argv):
    subprocess.run(argv, capture_output=True, text=True, timeout=10, check=True)


class Notifier:
    def __init__(self, runner=None, enabled=None, now=time.time, rate_s=RATE_S, keep=100):
        self.runner = runner or osascript_runner
        self.enabled = (os.environ.get("TC_NOTIFY") != "0") if enabled is None else enabled
        self.now, self.rate_s = now, rate_s
        self.events = deque(maxlen=keep)
        self._active = set()        # (project, kind, key) true in the last overview
        self._projects = None       # projects seen in the last overview; None before the first
        self._last = {}             # (project, kind) -> ts of the last event emitted
        self._seq = 0

    def observe(self, ov):
        """Compare one overview with the previous; return the events emitted (also appended to .events)."""
        now = self.now()
        cur = {(c["project"], c["kind"], c["key"]): c for c in conditions(ov)}
        events = []
        for k in sorted(set(cur) - self._active):
            c = cur[k]
            if self._projects is None or c["project"] not in self._projects:
                continue   # first overview, or a project that just appeared: seed only
            last = self._last.get((c["project"], c["kind"]))
            if last is not None and now - last < self.rate_s:
                continue
            self._last[(c["project"], c["kind"])] = now
            self._seq += 1
            events.append({"id": self._seq, "ts": now, **c})
        self._active = set(cur)
        self._projects = {p["project"] for p in ov.get("projects") or []}
        if not self.enabled:
            return []
        for ev in events:
            self.events.append(ev)
            self.banner(ev)
        return events

    def banner(self, ev):
        try:
            self.runner(banner_argv(ev["title"], ev["text"]))
        except Exception as e:   # noqa: BLE001 - a failed banner is logged and nothing else happens
            print(f"notify: banner failed: {type(e).__name__}: {e}", file=sys.stderr, flush=True)

    def recent(self):
        return list(self.events)
```

#!/usr/bin/env zsh
# tmux-overseer ensure|stop [--force]|status — the read-only overseer Claude, session `overseer` on the server the projects are on.
#   ensure   create the session when a project session with a `claude` window exists and `overseer` doesn't (TC_OVERSEER=0: never)
#   stop     kill the session once no project session remains (--force: now)
#   status   print running|stopped; exit 0|1
# Callers: tmux-dev-layout (ensure, so the first `dev` starts it), the board server (ensure on each overview build, so a
# killed overseer comes back), tmux-session-closed (stop). Never touches a project session. Test seam: TC_OVERSEER_CMD
# replaces the claude-overseer command line typed into the window.
emulate -L zsh
source "${0:A:h}/_tc_bins.zsh"; T=tc_tmux
source "${0:A:h}/_ab_claude.zsh"
OV=overseer
projects() {   # sessions with a `claude` window that are not the overseer, a -bg session or a _web- view
  local line s
  for line in ${(f)"$("$T" list-windows -a -F '#{session_name}'$'\t''#{window_name}' 2>/dev/null)"}; do
    [[ "${line#*$'\t'}" == claude ]] || continue
    s="${line%%$'\t'*}"
    [[ "$s" == "$OV" || "$s" == *-bg || "$s" == _web-* ]] && continue
    print -r -- "$s"
  done
}
case "$1" in
  ensure)
    [[ "$TC_OVERSEER" == 0 ]] && exit 0
    "$T" has-session -t "=$OV" 2>/dev/null && exit 0
    [[ -n "$(projects)" ]] || exit 0
    cmd="${TC_OVERSEER_CMD:-${(q)AB_REPO}/bin/claude-overseer}"
    # new-session is the atomic gate: a second caller racing this one loses and exits quietly
    "$T" new-session -d -s "$OV" -n claude -x 200 -y 50 -c "$AB_REPO" 2>/dev/null || exit 0
    "$T" set-option -t "=${OV}:" @tc_overseer 1
    "$T" send-keys -t "=${OV}:claude" -l -- "$cmd"
    "$T" send-keys -t "=${OV}:claude" Enter
    print -r -- "started the overseer (session $OV)" ;;
  stop)
    "$T" has-session -t "=$OV" 2>/dev/null || exit 0
    [[ "$2" == --force || -z "$(projects)" ]] || exit 0
    "$T" kill-session -t "=$OV" && print -r -- "stopped the overseer" ;;
  status)
    if "$T" has-session -t "=$OV" 2>/dev/null; then print running; else print stopped; exit 1; fi ;;
  *) sed -n '2,8p' "${0:A}" | sed 's/^# \{0,1\}//' >&2; exit 2 ;;
esac

- **Digest.** `board/overview.py` builds one record per project from state the board already has (no LLM): the active plan and `done/total` (planview), in-progress tasks with owners, "Needs you" panes, the last `tmux-ctl run` (command, exit, age), the lead's state and idle time (`#{window_activity}` of the `claude` window), the last three registered artifacts, the epoch, live usage alerts and today's spend (`usage.spend_since`). `GET api/overview` returns `{generated, projects, events, overseer}`; `tmux-ctl overview [project] [--json]` prints one line per project (or the JSON) from the running board, else a local build without usage data (`source: local`).
- **Notifier.** `board/notify.py`, run by a server thread every 10 s. It compares each overview with the previous one and emits six event kinds: `needs_you` (a pane starts waiting), `plan_done` (a plan's tasks are all complete), `test_failed` (a run ends non-zero), `lead_idle` (the lead ready for 15 min with open tasks), `context` (a session crosses `context_pct`) and `usage` (`burn_per_hour`, `session_total`, or the project's spend today over `day_total`). An event fires once when its condition appears, not again while it holds, again after it clears and returns; at most one of a kind per project every 5 minutes; the first overview and a project's first appearance only seed the state. Delivery: a macOS banner (`osascript -e 'display notification …'`; a failure is logged) and the events list the page turns into browser notifications and a `(n)` badge in the tab title. `TC_NOTIFY=0` turns it off.
- **The overseer agent.** tmux session `overseer` (one `claude` window) on the same server as the projects, started by `bin/tmux-overseer ensure` from `tmux-dev-layout` (so the first `dev` starts it) and from the board on each overview build (a killed overseer comes back), stopped by `tmux-session-closed` when the last project session goes. `bin/claude-overseer` runs `claude --model haiku --effort low -n overseer --settings claude/overseer-settings.json --append-system-prompt-file claude/overseer.md`, without the agent-board plugin. It is read-only by permission settings, not by prompt: `defaultMode: dontAsk` auto-denies every call no allow rule matches; allowed are Read, Grep, Glob, `tmux-ctl overview`, and read-only `git log/status/show`; Write, Edit, NotebookEdit, Agent, SendMessage and the writing `tmux-ctl` subcommands are denied outright. It answers from `tmux-ctl overview --json` first, then plan files, task lists, briefs and artifacts; asked to act, it names the project window to go to. `TC_OVERSEER=0` disables it; `TC_OVERSEER_CMD` is the test seam for the window's command. The board hides the `overseer` session from the project cards and shows its terminal on the home page.
